# Reto - Entrada de Usuarios

Este proyecto es una actividad donde se transforma un objeto de usuario en una estructura más organizada usando JavaScript.

## 👨‍💻 Autor
Kevin Andres Castillo Pabon

## 📌 Descripción

Se toma un objeto con datos básicos de un usuario y se reorganiza en una nueva estructura más ordenada.

Se aplicaron conceptos como:
- Desestructuración
- Renombramiento de variables
- Creación de objetos anidados

## ⚙️ Cómo funciona

1. Se crea un objeto llamado `entradaUsuario`
2. Se extraen sus datos usando desestructuración
3. Se renombran algunas propiedades (email → correo, telefono → contacto)
5. Se muestra el resultado en consola

## 🧪 Ejecución

1. Abrir el archivo `index.html` en el navegador
2. Abrir la consola con F12
3. Ver el resultado del objeto transformado

## 📁 Estructura

- index.html
- scripts/script.js

## 🎯 Objetivo

Aprender a organizar datos en JavaScript y prepararlos para ser enviados a una API.
